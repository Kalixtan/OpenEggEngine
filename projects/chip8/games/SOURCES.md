# Bundled game sources

The bundled CHIP-8 programs are from the [CHIP-8 Community Archive](https://github.com/JohnEarnest/chip8Archive). Its README places repository contents under CC0 1.0 (“No Rights Reserved”).
The ROM bytes are unchanged; `.hex` is only a text encoding for the script loader.
